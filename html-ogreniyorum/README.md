# HTML Öğreniyorum

HTML öğrenirken yaptığım ilk deneme sayfası. W3Schools uygulamasından çalıştığım konuları bir sayfada denedim.

## Kullandığım konular
- başlıklar, paragraflar, kalın ve italik yazı
- iç içe listeler
- tablo yapma ve colspan
- link, sayfa içi bağlantı (#id) ve resim ekleme
- class ve id ile CSS bağlama (ayrı style.css dosyası)
