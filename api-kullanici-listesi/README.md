# API Kullanıcı Listesi

AngularJS ile bir API'den kullanıcı verisi çekip tabloda gösterdiğim, arama yapılabilen ve kişi eklenip silinebilen bir sayfa.

## Kullandığım konular
- $http.get ile jsonplaceholder.typicode.com/users adresinden veri çekme
- ng-repeat ile tabloyu doldurma
- filter ile arama kutusu
- toplam kullanıcı sayısını length ile gösterme
- ng-click ile ekleme ve silme

## Not
Veriler kaydedilmiyor, sayfa yenilenince başa dönüyor. Sayfanın veri çekebilmesi için internet bağlantısı gerekir.
