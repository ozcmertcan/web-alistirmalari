# Web Alıştırmaları

AngularJS ve HTML öğrenirken yaptığım küçük alıştırmalar. Her proje kendi klasöründe, canlı halini linkten açabilirsin.

| Proje | Ne yapıyor | Canlı |
|---|---|---|
| [kitap-takip](kitap-takip) | Kitap ekleme, silme, güncelleme | [Aç](https://ozcmertcan.github.io/web-alistirmalari/kitap-takip/) |
| [kisi-tablosu](kisi-tablosu) | Kişi ekleme, silme, güncelleme | [Aç](https://ozcmertcan.github.io/web-alistirmalari/kisi-tablosu/) |
| [api-kullanici-listesi](api-kullanici-listesi) | API'den veri çekme, arama, ekleme, silme | [Aç](https://ozcmertcan.github.io/web-alistirmalari/api-kullanici-listesi/) |
| [html-ogreniyorum](html-ogreniyorum) | HTML ilk deneme sayfası | [Aç](https://ozcmertcan.github.io/web-alistirmalari/html-ogreniyorum/) |

Öğrenci tablosu projem ayrı bir repoda: [angularjs-ogrenci-tablosu](https://github.com/ozcmertcan/angularjs-ogrenci-tablosu)

## Kullandığım teknolojiler
HTML, CSS, JavaScript, AngularJS

## Not
Veriler kaydedilmiyor, sayfalar yenilenince başa dönüyor. Kişi tablosundaki veriler uydurmadır.
